# 已知限制、待验证与候选工作

更新：2026-11-16 / 0.107。这里区分确认的能力边界与待测项，不把猜测当 bug；没有默认授权的开发待办。

## 仍存在的能力边界

- 手身份依据关键点与检测标签/连续性，不是生物身份认证。如果两只真实手交替但所有可观测点及高置信标签相同，系统无法识别已换人/换手。0.93 合成反例已证明，不能宣传任意遮挡下永不混入。
- 原始真人交叉/强遮挡可能误标或丢点；稳定选手与录制保护覆盖可观察到的歧义，不能补造模型看不见的信息。
- 身体/面部学习单目标；双手/混合学习暂缓。面部/身体坐标四点上限仍在；不是本轮遗漏。
- 项目只在当前 origin 的浏览器本地，账号不做同步。清理浏览器数据会丢项目；桌面/网页/端口分开，迁移需导出导入。
- 参考音频受 localStorage 容量限制。服务端限流和会话撤销在内存，不跨实例共享。
- main.tsx/style.css 较大，改一处需检查相邻模式；不为小任务顺手拆全站。

## 后续候选（先由用户定范围）
