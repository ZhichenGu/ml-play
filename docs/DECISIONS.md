# 已确认的产品与设计决定

适用 0.107，2026-11-16。记录“为什么保持这样”，不是新增开发授权。

| 主题 | 决定与原因 |
| --- | --- |
| 手数 | 学习和规则只做单手；双手/混合学习先暂缓，避免维度、入口、设置和录制语义不一致。仅坐标在创建时选单/双手容量，工作台不重复切项目模式 |
| 单手选择 | 自动追踪一只，不询问左右手；保持当前控制手，另一只手不抢占。双手坐标有单手输出/双手输出，左右独立丢失恢复 |
| 坐标选点 | 手部可输出全部 21/42 点，不再限总四点。名称和 X/Y/Z 可预览，接收端可辨识；面部/身体当前仍最多四点 |
| 三种动态学习方式 | path 看整体移动、shape 看局部形变序列、both 两者；不是三种速度模型。新手部默认整体轨迹；一二三手势更适合局部形变 |
| 参考点 | 新手部默认掌心中心（0/5/9/13/17 均值），可明确选食指尖或手腕。形变关注点独立设置，不让“关注哪些手指”偷偷改整手轨迹参考；旧隐式参考保留 |
| 推荐标记 | 用户在三卡片介绍中确认哪种，就标记该种；不永久固定推荐整体轨迹。点击卡片仅预览，取消不应用 |
| 动作对照 | 只在动态模式提供；默认最新正向训练示范，可切旧示范；当前轨迹渐隐、丢失断开。根据 feature 画路径/骨架/两者，不用一条线解释形变 |
| 动作对照价值 | 是观察差异，非识别分数/正确性证明；回放不发输出。冻结回看的示范和当前片段，新增录制不替换正在看的内容 |
| 新手动画 | 所有交互进入工作台后有解释；手/脸/身体同一套卡片风格，视觉/声音沿用输入→结果。动画不是摄像头录像，不伪装 API 成功 |
| 视觉主次 | 示例问题突出，图形使用可辨识物体；删去无意义横线/形状、图下重复 cup/scissors 名称和重复操作说明 |
| 人物风格 | 面部自然、中性、柔和轮廓；不画面具/恐怖骨相，不夸张大 O 嘴，也不做幼儿卡通；手/脸/身体暖肤色、蓝点统一 |
| 强调色 | 低饱和暖杏橙用于动作对照和 P 字母外矩形；设置按钮整体仍白底。避免亮红/亮绿/亮黄强调大面积入口 |
| 白点/红点 | 六种手部交互统一小点；白点 75%，红点 100%；避免多个图层叠点增加不透明度 |
| 布局 | 保留白/浅灰/淡蓝体系、留白与中英；学习方式在项目标题旁可见；相机关闭时启动按钮在画框中央 |
| 设置面板 | 内容自动决定初始高度，长内容滚动；用户可拖动，各分类会话内记忆，短页不继承长页空白 |
| 保存/发布 | 项目自动保存，有真实结果反馈。MQTT/OSC 应用配置单独说明。源码、网页、安装包分别标状态；用户自己 push，不自动继续发布 |

未决定的想法不可当作已实现：双手动作共同学习、双手距离控制、更多自动化验收、下一次桌面发版。新需求以用户后续明确选择为准。
